# EzRide Website

A responsive, single-page landing website for **EzRide**, built with HTML, CSS, Bootstrap 5, and Bootstrap Icons.

## Project structure

```text
ezride-github-project/
├── index.html
├── README.md
└── .gitignore
```

## Run locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in a web browser.

The page loads Bootstrap 5, Bootstrap Icons, and the sample photos from public CDNs, so an internet connection is needed for those external resources.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `ezride-website`).
2. Upload the files in this folder to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Important note about the contact form

The current contact form is a front-end demo. It validates the fields and displays a confirmation message, but it does **not** send an email or save submissions. Connect it to a backend or a form service before using it to receive real messages.

## Customization

- Edit the page content and styles in `index.html`.
- Replace the sample Unsplash image URLs with your own images if desired.
- Update the Facebook page link, email address, and phone number with verified contact details before publishing.
